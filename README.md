# wjc bar · 暖心小酒馆

版本：`v1.2`

这是一个纯静态、可持续扩展的网页游戏原型。玩家经营一家雨夜小酒馆，观察顾客的情绪与人生片段，自由调制饮品、决定回应方式、布置氛围，并把发生过的事情留在酒馆日志里。

## 已实现的首个可玩版本

- 酒馆首页：时间、天气、室内环境、音乐提示、营业状态、当日小事，以及 4 种可切换的灯光/窗景/装饰/音乐氛围。
- 自由调酒实验室：12 种虚构材料、4 种做法、4 种杯型、4 种装饰、4 项风味滑杆，以及会随杯型/装饰/氛围变化的动态杯中预览；支持为配方自定义命名。
- 顾客与故事：5 位固定顾客（林弦、莫里、余照、沈岸、乔安），包含独立性格、背景、线索和再次来访进度。
- 故事记录：三条连续关系线的首版内容（林弦、余照、乔安），并预留其余人物的阶段进度；每次接待都会产生不同的文字反馈。
- 菜单系统：保存并命名配方、收藏为招牌、查看创作记录、载入后继续编辑；内置 10 杯原创饮品作为酒馆初始菜单。
- 自由模式：没有顾客压力，专门研究风味，实验结果也会写入日志。
- 本地进度：所有配方、接待次数、日志、自由模式、氛围选择、当前调酒状态和草稿名称通过 `localStorage` 保存；每次选择材料/调节滑杆/切换页面都会即时保存，刷新后恢复。它是浏览器本地存档，不是跨设备云存档。
- 静态资源缓存：`sw.js` 会缓存页面壳、脚本、样式和酒馆位图；在线刷新优先使用最新资源，断网时回退到缓存。Service Worker 只在 `http/https` 环境运行，直接双击 `index.html` 时不会注册，但 `localStorage` 存档仍然有效。
- 响应式布局：适配桌面端和移动端，无需服务器或后端服务。
- 连续对话：五位固定顾客各自拥有三次来访阶段；每次服务包含顾客开场、店主回应、顾客回话和再次回应，选择会写入故事日志并影响关系进度。对话是本地作者预设的分支文本，不调用 AI 接口。

## 本地运行

本项目没有构建步骤和依赖。直接双击 `index.html` 即可体验；也可以在项目目录启动任意静态服务器，例如：

```bash
python -m http.server 8080
```

再打开 `http://localhost:8080/`。

## GitHub Pages 部署

1. 将本目录内容放入 `wjc-bar` 仓库根目录。
2. 在 GitHub 仓库的 Settings → Pages 中选择 GitHub Actions，或选择部署分支的根目录。
3. 本项目入口是根目录的 `index.html`，无需配置环境变量、数据库或服务器。

本地进度只保存在每位玩家自己的浏览器中，不会跨设备同步。

## 素材来源说明

见 [`ASSET_SOURCES.md`](ASSET_SOURCES.md)。首版没有使用真实品牌、真实酒类包装、外部图片、外部音频或第三方 Logo。酒馆插画、瓶罐/杯中效果、图标和装饰均由 CSS、HTML 和文字符号原创绘制。页面字体使用 Google Fonts 的公开字体引用；若需要完全离线部署，可以按说明替换为本地字体或系统字体。

## 后续扩展建议

- 将每日天气、音乐和季节变成可解锁的氛围事件。
- 为 5 位顾客补齐 3 个阶段的显式分支与特殊来访条件。
- 增加“比例”编辑、调酒过程动画和可导出的配方卡片。
- 加入菜单季节版本、食材采购与酒馆升级，但保持轻量、非数值堆叠的经营感。
- 添加离线 Service Worker，进一步提升 GitHub Pages 的离线体验。
